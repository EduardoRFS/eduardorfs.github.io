Installing my Arch Linux

Unlike Windows, macOS and other Linux distro’s, Arch Linux is not exactly a “prebuilt” operating system, it is a set of tools to build your own OS, as such using Arch Linux is not a single experience, each installation is pretty much unique with it’s own upsides and downsides.

YAGNI

I’ve been coding and using Linux for more than a decade and during this time I noticed one useful principle, “You aren’t gonna need it” (YAGNI), applies to pretty much everything, as you add more “stuff”, it breaks more often and it get’s harder to fix.

As such my OS is quite bare, having tools for all my needs, but no more than that. In practice that makes it quite stable and maintanence free.

My install

This will be more or less a tutorial, it is still up to you to figure out some steps tho.

Arch Shell

To start, get yourself on an Arch shell, this can be done in a couple ways, commonly you can download an .iso from https://archlinux.org/ flash it on an USB stick and boot from it.

Alternatively, if you’re already in a Linux system, this can be done by downloading a bootstrap root image instead and using chroot. Be careful as this only allows you to install from one system to another, meaning that the original system still needs to work somehow, this is especially useful when installing Arch on a server. https://wiki.archlinux.org/title/Chroot
